# Phase 1B-2 value-risk frontier result — 2026-08-03

**The contributors whose data adds the most distinct coverage to a pooled release are the
least identifiable in it.** Rank correlation -0.569 between coverage value and exposure,
permutation p 0.0065, bootstrap 95% CI [-0.774, -0.202], negative in all 10 seeds.

At contributor level the record-level value-risk correlation does not hold. On the one
value axis that works, it points the other way.

> This document replaces an earlier version that reported **two** value axes and called
> one of them a null. Checking the second estimator against a majority-class baseline
> showed its model scores *below* that baseline at every seed.
> That is a failed measurement, not an absence of signal. There is one working value axis.

## The working axis: coverage value against exposure

| | |
|---|---|
| Spearman rho (10-seed mean lift) | **-0.5686** |
| Permutation p (20000 permutations) | **0.0065** |
| Bootstrap 95% CI over tenants | **[-0.774, -0.202]** |
| Per-seed rho | -0.539 to -0.107, negative in **10/10** |
| Controlling for task success rate | -0.526 |

Coverage value is a tenant's share of a 500-trace greedy coverage set divided by its share
of the pool. Above 1.0 means the tenant supplies more distinct representation than its
volume would predict. Exposure is per-tenant recall from the supervised re-identification
attack, averaged over 5 seeds.

**The direction is not a task-success artefact.** Coverage lift correlates +0.589 with a
tenant's task success rate, so some of what coverage rewards is simply succeeding.
Partialling success out moves rho from -0.569 to -0.526, so it accounts for very little of
the relationship.

**The direction is not explained by within-tenant homogeneity either.** The obvious
mechanism would be that coverage rewards internal diversity while re-identification rewards
internal consistency. Homogeneity does predict exposure strongly (+0.632, a contributor
whose traces resemble each other is easy to classify), but its relationship to coverage lift
is -0.065, near zero. So homogeneity explains the exposure axis and almost nothing about the
correlation. **The relationship is real and unexplained.**

## The broken axis: downstream utility

```
accuracy 0.7287   majority baseline 0.7616   AUC 0.4713
VERDICT: NO SKILL
```

The utility estimator trains a task-success predictor and measures how much held-out
accuracy drops when each tenant is removed from training. On this corpus that predictor is
**3.3 points worse than always predicting failure**, with AUC at chance. Task success has a
24% base rate; the model predicts positive on 4.5% of held-out rows.

Every per-tenant delta it produces is therefore a difference between two accuracies of an
unskilled model. Its correlation with exposure (rho -0.090) is recorded here only to
document the failure. **It is not evidence about the value-risk question in either
direction.**

The estimator is not fixable by more seeds. With an *ungrouped* split the same model
reaches AUC 0.845, so task success is predictable from the representation — but only via
task identity, and nothing generalises across held-out tasks. A working version needs a
different target (per-task-normalised success, or within-task ranking), which is a design
change rather than a fix.

`UtilityResult` now carries `majority_baseline` and `baseline_auc`, and the CLI prints a
warning when the model has no skill, so this cannot be read as a null again without the
reader seeing why.

## What this means against the literature

Wen, Backes and Zhang (NDSS 2025) measured 10.2x and 27.9x higher TPR at 1% FPR for
high-importance **records**. El Mestari et al. (SECRYPT 2025) tested it across
federated-learning **clients** and found no significant correlation.

This is the first measurement at contributor level in agent traces. It lands with El
Mestari, and on the coverage axis it goes further: the relationship is reliably negative.

For a marketplace, paying contributors by distinct coverage does not systematically expose
the most valuable suppliers. That is one correlation, on one corpus, between an ad-hoc
coverage proxy and one attack's recall — it is evidence against a specific worry, not a
licence to skip mitigation. Exposure remains real and unevenly distributed regardless:
Phase 1A measured per-tenant recall from 0.072 to 0.479.

**And anyone pricing on coverage should know it correlates +0.589 with task success.** A
coverage-based payout would substantially be paying contributors for succeeding, which may
or may not be the intent.

## Limitations, stated plainly

**The coverage axis barely reproduces itself.** Mean pairwise Spearman between per-seed
lift vectors is **+0.466**, so roughly half the variance in any single-seed ranking is
estimator noise from stochastic-greedy path variance. This is why the headline uses a
10-seed mean rather than one draw, and why the bootstrap CI is the honest interval rather
than the per-seed spread. An earlier version of this document reported three single-seed
runs and claimed "p at or below 0.05 every time" — that was three lucky draws presented as
robustness.

**The negative direction was not pre-committed.** The plan anticipated a positive
correlation, a null, or the two axes disagreeing. A stable negative was not on the list, and
an unanticipated direction deserves more caution than an expected one because no prior
commitment constrains the framing.

**n = 22.** A rank correlation at this size detects only large effects. The bootstrap CI
[-0.774, -0.202] is wide and its upper end is close to zero.

**The exploratory analyses are post hoc.** Homogeneity, task success rate and row count
were all examined after the headline was known, on the same data. They are reported as
context and as one refuted hypothesis, not as findings.

**Coverage is a proxy.** The 1 - 1/e guarantee bounds coverage, not value and not fairness.
It is used because exact game-theoretic attribution is intractable.

**Coverage-based payout resists duplicate padding only when a contributor has no
interchangeable peer.** Two tenants in the same region split its coverage budget
arbitrarily, so extra rows make one more likely to win those picks and partly offset the
dilution. Verified on synthetic data during implementation.

**Exposure assumes a labelled adversary.** Phase 1B-1 showed an adversary holding only the
pool cannot partition it at all (ARI 0.020 whole-pool, 0.017 held-out).

**The tenant is a model, not a company.** Real companies differ in more dimensions, so
separability here is a lower bound.

**The n-gram vocabulary is still derived across the whole corpus before any split**, so the
training-fold discipline does not extend to column selection. Verified numerically inert in
Phase 1B-1 but not fixed.
